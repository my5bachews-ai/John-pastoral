Architecture Overview
John (frontend) ↔ Your Backend Server ↔ Travel APIs (Amadeus, Booking.com, Stripe)
// John never calls travel APIs directly // Your backend holds all API keys and payment tokens securely // John sends intent → backend executes → returns results Frontend (John) ──POST /api/search──▶ Your Backend ──▶ Amadeus Flight API Frontend (John) ──POST /api/book──▶ Your Backend ──▶ Stripe + Airline API Frontend (John) ──POST /api/vault──▶ Your Backend ──▶ Encrypted DB (Supabase)
1. Search Flights
POST/api/travel/search/flights
{ "user_id": "pastor_abc123", "origin": "DAL", "destination": "ATL", "depart_date": "2025-05-24", "return_date": "2025-05-27", "passengers": 1, "cabin": "economy", "max_stops": 0, "preferred_airlines": ["DL", "WN"] } // Returns: array of flight options sorted by value score // Include: price, airline, times, stops, loyalty_points_earned, booking_token

3. Confirm & Book (Autonomous)
POST/api/travel/book
{ "user_id": "pastor_abc123", "payment_token": "stripe_pm_xxxx", // Never raw card — always Stripe token "flight_token": "amadeus_offer_xxxx", "hotel_token": "booking_prop_xxxx", "car_token": "enterprise_rate_xxxx", "autonomous": false, // true = no confirmation UI needed "traveler": { "name": "Pastor James Carter", "email": "pastor@gracefellowship.com", "tsa_number": "TSA-XXXXX" } } // Returns: confirmation numbers for all booked items // Triggers: confirmation email to pastor, calendar invite, 24hr reminder notification

Recommended APIs & Services
// Flights: Amadeus for Developers (amadeus.com/en/developers) // free tier: 2,000 calls/month // production: usage-based pricing // Hotels: Booking.com Affiliate API or Expedia Rapid API // both offer revenue-share models // Car Rental: Enterprise API or Rentalcars Connect API // Payments: Stripe (stripe.com) — SetupIntents for saved cards // PCI compliant, pastor never sees raw card in your DB // Database: Supabase — store vaulted preferences, trip history, loyalty #s // Row-level security ensures each pastor sees only their data // Notifications: Twilio (SMS) or web-push for booking confirmations + reminders // Estimated backend build time: 2–3 weeks for a competent developer // Stack recommendation: Node.js + Express + Supabase + Stripe
